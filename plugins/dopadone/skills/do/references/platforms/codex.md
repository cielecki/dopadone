# Codex

Use the current host's shell/file tools and discover installed skills by capability.
Run the shared configuration helper before picking or researching a task. Codex does
not need Claude's bang-command syntax or `CLAUDE_PLUGIN_DATA`; shared XDG configuration
and the existing legacy files work without that environment variable.

This package exposes the explicit `do` workflow. Claude's health-rhythm lifecycle
hooks, OS notifications, and automatic per-turn time/reminder injection have not
been ported to Codex. Do not claim they are running or create a substitute automation.
The explicit pick/named-task workflow and its approval/outcome boundaries still apply.
